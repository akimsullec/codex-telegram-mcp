# Шаблон диалога подключения

Показывать поэтапно на языке текущего чата. Не выводить вымышленные сообщения пользователя как реальные и не считать пример подтверждением.

1. Пользователь просит выполнить действие Telegram без настроенного входа: вывести полный текст `onboarding.md`. Затем ждать ответа.
2. Пользователь: **Готово.**
3. Codex после успешного открытия локального интерактивного окна:

   Открываю терминал >\_ PowerShell. Следуйте подсказкам в нём. После успешного входа напишите сюда **«Авторизация завершена»**.

4. Пользователь: **Авторизация завершена.**
5. Codex: проверить status, затем продолжить исходную задачу в рамках предоставленных разрешений. Не объявлять успешный вход или отправку без проверки. Сообщение адаптировать к задаче; для исходного примера:

   Проверяю настройку Telegram и продолжаю исходную задачу — отправку ссылки на резюме.

Если открыть окно не удалось, сообщить фактическую ошибку вместо утверждения о запуске.
